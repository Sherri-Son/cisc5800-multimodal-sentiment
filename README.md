# When AI Misreads Us

**A behavioral analysis of multimodal sentiment models on social media posts.**

Final project for CISC 5800 (Machine Learning), Fordham University M.S. Data Science.
Author: [Sherri Son](https://github.com/) · May 2026

---

## TL;DR

We benchmark five multimodal sentiment classifiers on the MVSA-Single Twitter dataset. Aggregate accuracy is misleading. **When the test set is partitioned by whether the unimodal classifiers agreed, every model loses 23 to 45 macro-F1 points on the disagreement subset** — the regime where sarcasm, irony, and culturally-coded meaning live.

| Model | Macro-F1 | F1 (agree) | F1 (disagree) | Drop |
| :--- | :--- | :--- | :--- | :--- |
| CLIP zero-shot | 0.383 | 0.396 | 0.358 | −3.8 pts |
| Text SVM (DistilBERT) | 0.575 | 0.757 | 0.310 | **−44.7 pts** |
| Image SVM (CLIP) | 0.622 | 0.757 | 0.419 | −33.8 pts |
| **SVM Fusion (RBF)** | **0.668** | **0.759** | **0.505** | −25.4 pts |
| Attention MLP | 0.603 | 0.697 | 0.463 | −23.4 pts |

The SVM Fusion wins on aggregate. The Attention MLP narrowly loses on aggregate but has the smallest drop between regimes, plus interpretable per-post gating weights. Both lose roughly a quarter of their macro-F1 the moment text and image disagree.

---

## Why this project exists

Automated content moderation now decides what billions of posts a day look like on Instagram, TikTok, and YouTube. Those systems are built on the same architectural family — multimodal encoders, attention-based fusion, classifier heads on frozen features — that we benchmark here. If a small academic benchmark with hand-labeled tweets cannot be reliably classified when the two modalities conflict, then the production systems applying related techniques to billions of posts are unlikely to do better. This repo is the smallest reproducible version of that argument.

## Method in one paragraph

We use the standard MVSA-Single reconciliation protocol from Niu et al. 2016 — keep matching labels, prefer the non-neutral label when one annotator says neutral, drop the 358 directly contradictory cases — giving 4,511 usable posts. We extract 512-dim CLIP-ViT-B/32 image features and 768-dim DistilBERT [CLS] text features once and cache to disk. Three RBF-kernel SVMs (text only, image only, concatenated fusion) are tuned via `PredefinedSplit` on the validation set with `class_weight='balanced'` to handle the 10% neutral class imbalance. An attention-gated MLP projects each modality to a shared 256-dim space, applies a softmax over a learned scalar gate per modality, and feeds the weighted sum into a 128-hidden-unit classifier with dropout. CLIP zero-shot uses prompt-based cosine similarity as a no-training baseline. Everything is evaluated on macro-F1 to avoid being flattered by the 60% positive class.

## The headline finding

Aggregate macro-F1 looks like the SVM Fusion modestly wins, with everyone else clustered within 10 points. That picture changes the moment you split by modality agreement.

We define the agreement subset as test posts where Text SVM and Image SVM predict the same class (427 posts, 63.1%) and the disagreement subset as everything else (250 posts, 36.9%). On agreement, all four trained models score between 0.697 and 0.759. On disagreement, scores collapse to 0.310 – 0.505.

The disagreement subset *is* the sarcasm and irony subset, almost by construction: it's the set of posts where the text channel and the image channel are sending different signals, which is the linguistic signature of meaning living in the gap between modalities. Every model loses substantial F1 there, and none of them really learns to resolve such conflicts.

## Behavioral case taxonomy

Aggregate metrics tell you *how often* a model is right. They don't tell you *who* it gets wrong. We tag every test prediction with one of ten behavioral patterns, grouped into four families:

| Group | Pattern | Meaning |
| :--- | :--- | :--- |
| **Save** | Text-driven save | MLP correct, SVM fusion wrong, attention ≥ 0.6 on text |
| **Save** | Image-driven save | MLP correct, SVM fusion wrong, attention ≥ 0.6 on image |
| **Save** | Modality conflict resolved | Unimodal SVMs disagree, MLP picks correctly |
| **Save** | Fusion creates new signal | Both unimodal SVMs wrong, fusion recovers |
| **Harm** | SVM fusion breaks signal | Both unimodal correct, concatenated fusion wrong |
| **Harm** | MLP overrides correct SVM | SVM fusion correct, attention MLP wrong |
| **Pattern** | Zero-shot beats trained | Only CLIP zero-shot gets it right |
| **Pattern** | Neutral collapse | True label is neutral; MLP sends it elsewhere |
| **Baseline** | Unanimous agreement | All 5 models correct |
| **Baseline** | Universal failure | All 5 models wrong — often a label-noise smoke signal |

See `figures/case_gallery_extended.png` for 20 real test posts annotated with each model's prediction and the MLP's attention weights.

## Four real cases that illustrate the pattern

**Text-driven save.** Tweet: *"Heartbreaking moment when you realise you've got sparkling water instead of still ??"* paired with a generic bottle photo. Gold label: negative. Four models predict positive; the Attention MLP correctly predicts negative with 0.94 attention on the text. The word *heartbreaking* is the dominant signal and the gate correctly downweights the bland image.

**Image-driven save.** Tweet: *"RT @kjo19: Hey Blue Jays Nation......"* paired with the *Are you not entertained?* Gladiator meme. Gold label: positive. Four models predict negative; the Attention MLP correctly predicts positive with 0.98 attention on the image. With near-empty text content, the gate defers to the visual signal.

**Lexical trap.** Tweet: *"If everyone does their small part, we will change HEARTS AND MINDS about depression this year. Let's band together."* Gold label: positive (awareness campaign). SVM Fusion correctly predicts positive; the Attention MLP misclassifies as negative. A single high-charge word, *depression*, overrides surrounding context and the gating mechanism cannot recover.

**Label noise as ceiling.** Tweet: a sharply critical post about Christian Grey, signed off with *"happy valentines day :)"*. Gold label: positive. All five models predict negative or neutral. The gold annotation almost certainly weighted the closing valentine over the content. This is not a model failure; it is a label failure, and a meaningful share of universal-failure cases on MVSA-Single show similar issues.

## Limitations

This project is a behavioral analysis, not a state-of-the-art result. A few things to keep in mind before generalizing:

* **Dataset scale.** MVSA-Single has only 4,511 usable posts. Findings may not transfer to larger benchmarks.
* **Frozen encoders.** We do not fine-tune CLIP or DistilBERT. Fine-tuning could change the relative ranking of fusion strategies.
* **Single sentiment scheme.** We use the three-class scheme defined by MVSA. Real moderation systems operate on multi-label policy categories.
* **Single training run.** Results are from one run with fixed seed. A rigorous treatment would report variance across multiple seeds, especially for the Attention MLP.
